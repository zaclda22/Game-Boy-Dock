# Game-Boy-Dock
I use a raspberry pi pico for this project and modified snes controller.

# Hardware Required :
- [Raspberry Pi Pico](https://www.raspberrypi.com/products/raspberry-pi-pico/)
- [DVI/HDMI Sock](https://www.adafruit.com/product/5957)
- Some Resistance
- Some Different Cable
- Signal Diode
- USB Cable
- Old or Cheap Controler
- 1 Button
- Game Boy and Games

# How to construct the Hardware
1. Look at the schematic
2. Build the circuit as you wish
3. Test it !!

# How to run
1. Download the latest `.uf2` in the [Release](https://github.com/zaclda22/Game-Boy-Dock/releases) section
2. Copy it
3. Hold down the BOOTSEL button while plugging the Raspberry Pi Pico into your computer
4. Paste the file in the drive named `RPI-RP2` or another device name like that
5. The Raspberry Pi Pico device while start the program
   
# How to compile
# Windows :
1. Download [Visual Studio Code](https://code.visualstudio.com/)
2. Install the Raspberry Pi Pico Project extension
3. Clone the project on your PC `git clone https://github.com/zaclda22/Game-Boy-Dock.git`
4. Open the folder `Code` in VS code
5. Launch the Raspberry Pi Pico Project extension from the tool bar
6. Click on `Compile Project`
7. When the build finish go in the build folder and copy the `.uf2` file
8. Hold down the BOOTSEL button while plugging the Raspberry Pi Pico into your computer
9. Paste the file in the drive named `RPI-RP2` or another device name like that
10. The Raspberry Pi Pico device while start the program
